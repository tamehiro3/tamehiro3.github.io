# ⑨ 投稿用キャプション — ep25（【PR】いちばん使ってる教材「明鏡」・紹介の仕組みと厳選した2つ）

動画：`episodes/ep25/out/ep25.mp4`

この回は**広告（PR）**です。プロフィールに置くBrainの紹介リンクから買われると、ためひろさんに紹介報酬が入ります。広告だと分かるようにしているのは次の4か所です。
- 画面：0秒目から最後まで、左上に「PR・紹介報酬あり」のラベル（濃紺の「PR」＋白地の「紹介報酬あり」）
- 声：2〜4文目（PRであること、紹介の仕組み、このリンクから買われると紹介料が入ること）
- 見出し：2文目に「これはPRやで」、3文目に「紹介の仕組み」
- キャプション：1行目

## 投稿前のチェック
- [ ] **5文目「ほかの店にもあるから、あなたもPR付けて試してみ」は、紹介の仕組みそのものの話にとどめる**
  - 明鏡の公式FAQでは、明鏡を紹介できるのは**買った後**（紹介報酬は当面50%）とされている。なので「明鏡を買って、あなたも紹介して紹介料を」とつなげると、「買う→人に紹介すると報酬」という連鎖販売取引（いわゆるモノなしマルチ）と同じ形になる。動画でもキャプションでもコメントでも、この2つを結び付けない
  - 「1件売れたら1万4,900円」「2件で元が取れる」「半額返ってくる」「紹介料50%」は言わない・書かない
  - 「あなたも試してみ」は、買わなくても使える紹介の仕組み（ほかのお店の紹介プログラムなど）を、自分が本当にええと思ったものに使う話。紹介するときはPRと書く、までにする
- [ ] **「クーポン」とは言わない**：紹介リンクから買っても、買う人の値段は安くならないとみられる（発売前の10%オフはもう終わっている）。「クーポン」と言うと割引があると受け取られるので、たとえは「ええ店を友だちに教えたら、お店からお礼が出る」にしている。Brainの明鏡のページで、紹介リンクから買うと値段が変わらないことを確かめる
- [ ] **ためひろさん本人に確かめる**
  - いちばん使っている教材は明鏡か（6文目）
  - 10文目「失敗しやすいとこを先に教えてくれる」と11文目「どんな商売にもつながる土台の考え方」は、ためひろさんが実際に読んで思ったことか。公式の説明やレビューでは、失敗例をまとめた章があるとは確認できていない。台本では「僕が厳選して紹介したい」「僕の感想では」と、ためひろさんの感想として言っている
  - 12文目「お金の悩みを、自分の力でなんとかしたい人向け」は、ためひろさんの感想（見出し「僕の感想では」）。イケハヤさんはXで「マーケティング初学者向け」と書いている
- [ ] **Brainの販売ページを自分の目で開いて確かめる**（どれも検索結果の要約で確認しただけ）
  - 値段が **29,800円** か、**税込み**か（14文目）。投稿前に変わっていたら14文目を作り直す
  - 受付が **毎月1日〜5日** か（15文目）。10/20〜10/31に出すと、見た人は次の受付（11/1から）まで買えない
  - 返金は **原則なし** か（14文目）。公式FAQでは「デジタルコンテンツの性質上、原則として返金・返品には対応しておりません」、あわせて「購入前に無料の学習サイトで雰囲気を確かめて」と案内している
  - 紹介リンクの行き先が「明鏡」のページか
  - 公式ページの「49,800円へ値上げ予定」を使って急がせない
- [ ] **「数億円」の出どころ**（8文目）：イケハヤさん本人のnote（https://note.com/ihayato/n/nf46a938f7acd ）。2016〜2021年の有料コンテンツとオンラインサロンの売上の合計で約5億円（本人の申告。売上で、利益ではない）。今も毎年数億円売っているとは言わない
- [ ] **しゅうへいさんの音声番組に「初心者がイケハヤ教材『明鏡』を買ってはいけない理由。」という回がある**という情報がある（未確認）。ep30でしゅうへいさんの商品を紹介するので、両方を見た人に矛盾と取られないか、その回を一度聞いて確かめる

  - 2文目の「PR」が「ピーアール」とはっきり聞こえて、6秒以内に入っているか

### 言わない・書かないこと（コメント欄も同じ）
- 「稼げる」「月○万」「誰でも」「すぐ」「最強」「No.1」「人生変わる」
- 「クーポン」「お得に買える」「僕のリンクから買うと安い」：割引はない
- 「明鏡を買えば紹介で元が取れる」「あなたも明鏡を紹介して稼げる」「紹介料50%」「1件で1万4,900円」：買うことと紹介料を結び付けない（連鎖販売取引の形になる）
- 「今だけ」「もうすぐ締め切り」「今月中に」「次の受付は○日から」「値上げ前に急いで」
- 値上げ予定（49,800円）：急がせる言い方になり、二重価格にも見えるため書かない
- 「案件ちゃうで」「第三者の正直な感想」「ステマちゃう」：紹介報酬がある以上、広告として扱う
- 「イケハヤさん公認」「コラボ」「イケハヤさんが教えてくれる」：提携や直接の指導があるように見せない。イケハヤさんの写真・ロゴ・販売ページの画像も使わない
- 「失敗例が全部載ってる」「どんな商売でも成功する」：ためひろさんの感想として言う。教材の中身を言い切らない
- 「イケハヤさんは毎年数億円稼いでる」「数億円稼げる方法が学べる」：本人の発信は過去の累計の売上で、利益でも、視聴者の収入の話でもない
- 「25万字」「講義動画1,200本」「2600部突破」：確かめられていない、または、みんな買っていると思わせる数字
- 「教材に台本のテンプレが入ってる」「AIに読み込ませてOK」：確認できていない
