# 7つのSNSの性質 — どの場で、どの欲望が動くか

2026-09時点の**定性的な**整理。利用者層の数字・規約・収益化の条件・リンクの扱いは変わるので、設計図に使う前に公式の資料（各社のヘルプ・媒体資料、総務省の情報通信メディアの利用時間と情報行動に関する調査など）で確かめ、確かめた日付と出典を書く。ここに利用者数などの数字を書かないのは、古い数字が設計を狂わせるから。

## 2. SNSごとの性質

各SNSを同じ項目で並べる。設計図のSNSカードは、ここを出発点に事業に合わせて書き換える。

### X
- **開く理由**: 今起きていること・意見・本音を読む。テキスト中心で、界隈（クラスタ）ごとに文化が違う。
- **届き方**: おすすめ表示とリポストで、フォロー外に一気に届く。返信や引用で議論が起きると伸びる。
- **動く欲望**: 一発逆転・自由（副業・投資の界隈）、資産防衛、推し、時間（経営者の発信）、性欲（成人向けはラベルと年齢制限が前提）。
- **型**: 1投稿1話題。結論や数字から書く。長い話はスレッドに。毎日。固定投稿でリスト登録へ。
- **導線**: プロフィール・固定投稿・返信欄。外部リンク付きの投稿は表示が伸びにくいという見方が多い（要検証）。
- **禁止線**: 自動化のルール（自動の一括メンション・自動いいね・同じ内容の繰り返し投稿）、成人向けはセンシティブ設定、なりすまし、広告であることを隠す投稿（ステマ規制）。APIでの投稿は有料（料金は公式で確認）。
- **見る数字**: 表示回数、プロフィールへのアクセス、リンクのクリック、リスト登録数。

### Instagram
- **開く理由**: 憧れ・世界観・暮らしを「見る」「保存する」。写真と動画が中心。
- **届き方**: リール（フォロー外へ）、カルーセルや写真（保存されると広がる）、ストーリーズ（フォロワーと毎日触れる）、DM。
- **動く欲望**: 美貌、ラク（時短家事・レシピ）、子どもの未来（知育・おうち遊び）、プロテイン（体づくり）、承認、推し。
- **型**: カルーセル（1枚目で結論、保存したくなる教科書型）、リール（冒頭で掴む）、ストーリーズ（日常・質問・アンケート）。画像は縦長（4:5）が基本で、横長だと小さく表示される。
- **導線**: 通常の投稿にはリンクを貼れない。プロフィールのリンク、ストーリーズのリンク、DM。
- **禁止線**: 性的・露骨な表現、化粧品・健康食品の効能表現（薬機法）、美容医療の広告規制、タイアップの表示（ステマ規制）。13歳未満は利用できないので、子ども向け商品は親に話す。
- **見る数字**: 保存数、プロフィールへのアクセス、リンクのタップ、DMの数。

### TikTok
- **開く理由**: 暇つぶしに流れてくる動画を見る。若い層では検索の代わりにも使われる。
- **届き方**: おすすめ表示がフォロワー数と関係なく配信するので、ゼロから見込み客を集める力が最も強い。冒頭の数秒で見続けるかが決まる。
- **動く欲望**: 承認、美貌、推し、一発逆転（若い層）、ラク（生活の小技）、プロテイン。
- **型**: 縦長の短い動画。冒頭で結論か問い。シリーズにする。コメントへの返信動画。
- **導線**: 「続きはプロフィールから」。プロフィールのリンクは条件つき（アカウントの種類や規模。要確認）。
- **禁止線**: 未成年の保護（13歳未満は利用できない、10代への配慮）、性的な表現、危険な行為、医療・健康の誤った情報、ステマ規制。
- **見る数字**: 最後まで見られた率、平均視聴時間、プロフィールへのアクセス、フォローされた率。
- **客層の注意**: 購入率は低くなりやすい。見込み客をここで集め、別の場（メール・長尺動画）で信頼を積む前提で設計する。

### YouTube
- **開く理由**: 調べる・学ぶ・テレビ代わりに長く見る。検索エンジンとしても使われる。
- **届き方**: 検索（動画が資産として長く残る）、おすすめ、Shorts（短い動画でフォロー外へ）、ライブ。
- **動く欲望**: 健康（中高年は長い動画をテレビ代わりに見る）、資産防衛、時間、子どもの未来、プロテイン、丸投げ（やり方の解説）。
- **型**: 長尺（検索される言葉をタイトルに、サムネイルで一目で分かる）、Shorts、ライブ。週1〜2本。
- **導線**: 概要欄のリンク、固定コメント、動画の中での無料特典の案内。
- **禁止線**: 子ども向けの設定（子どもに向けた動画は「子ども向け」に設定する義務があり、コメントやパーソナライズ広告などが制限される）、医療の誤った情報、薬機法、有料プロモーションの表示。
- **見る数字**: 検索からの流入、視聴維持率、サムネイルのクリック率、概要欄リンクのクリック、チャンネル登録数。
- **客層の注意**: 長く見てもらえるぶん信頼が積み上がり、高単価の商品や個別相談につながりやすい。富裕層レバーの本拠地。

### Substack
- **開く理由**: 信頼する書き手の長い文章を、メールで受け取る。
- **届き方**: メール（アルゴリズムに左右されない）、Substackの中の推薦やNotes。日本語の読者の回遊はまだ小さいという見方が多い（要確認）。
- **動く欲望**: 資産防衛、時間（要約・目利き）、自由（独立・キャリア）、推し（書き手のファン）、専門の知識。
- **型**: 週1の定期便。1通1テーマ。無料と有料の切り分け。
- **導線**: ほかの全SNSのプロフィールから、ここへ登録してもらう（受け皿）。読者のメールアドレスは書き手が持ち出せる。
- **禁止線**: 外部からの自動投稿は前提にしない（規約を確認）。特定電子メール法（同意・配信停止・送信者の表示）。
- **見る数字**: 登録数、開封率、有料への転換率、解約率。
- **位置づけ**: SNSのフォロワーは借り物。規約変更や凍結で一夜で失う。自分のリストに橋を架ける場として、どの事業でも1つは持つ。

### note
- **開く理由**: 日本語の読み物・体験談・学びを読む。有料記事・マガジン・メンバーシップで少額から売れる。
- **届き方**: noteの中のおすすめ・タグ、検索エンジン、Xなどからの流入。
- **動く欲望**: 自由（会社員のキャリア・副業）、子どもの未来（育児・教育のエッセイ）、ラク、一発逆転（副業）、時間。
- **型**: 体験談・失敗談・手順書。無料部分で価値を渡し、有料の区切りの前で続きを読みたくさせる。週1〜2本。
- **導線**: 記事の最後のリンク、プロフィール。フォロワーはnoteの中の資産で、持ち出せない。
- **禁止線**: 規約とガイドライン（性的な表現・誇大な表現・情報商材の扱い）、景品表示法、ステマ規制。
- **見る数字**: スキ、フォロー、有料記事の購入率、メンバーシップの継続率。

### Brain
- **開く理由**: 知識やノウハウを買う市場。買い手は「稼ぐ」「効率化」の答えを探して来ている。
- **届き方**: Brainの中のランキングやカテゴリ、そして紹介（アフィリエイト）の仕組みで、購入者や紹介者が自分のSNSで広める。Xからの流入が中心と言われる（要確認）。
- **動く欲望**: 一発逆転、自由、時間、丸投げ（テンプレ・ツール）。
- **型**: 常設の販売ページ。無料部分で目次と中身の価値を見せ、レビューを積む。
- **導線**: 購入者を自分のリスト（メール）へつなぐ特典。規約の範囲で。
- **禁止線**: 収入・成果の断言。紹介者の誇大な宣伝（販売者の責任を問われうるので、使ってよい実績と禁止表現を紹介者に渡す）。特定商取引法の表示。紹介であることの明示（ステマ規制）。
- **見る数字**: 販売ページの閲覧から購入までの率、紹介経由の割合、返金とレビュー。
- **客層の注意**: 貧乏レバー（近道・可能性）が最も効く場で、そのぶん誇大表示が起きやすい。一発逆転を売るなら、`desires.md` §4 の線を先に書いてから設計する。買い手が「稼ぐ」以外の目的で来ない事業には向かない。

## 3. 一覧にないSNSを足すとき

ユーザーがすでに使っている場（Threads・Bluesky・LINE・Facebook・Podcastなど）は、設計図の先頭に足す。7つのうち性質が近いものを出発点にする。

| 場 | 近いもの | 違い |
|---|---|---|
| Threads | X | 文字の場だが、議論より会話寄り。Metaの規約 |
| Bluesky | X | 時系列の表示が中心で、拡散の仕組みが違う |
| LINE公式アカウント | Substack | 受け皿。開封されやすいが、配信数で費用がかかる |
| Facebook | YouTube（中高年） | 中高年・地域・グループ |
| Podcast | YouTube（長尺） | 耳だけ。ながら聞きで信頼が積み上がる |
