# 6分野と13の欲望 — 誰が、何の痛みを消すために払うか

人がお金を払うのは、生きていく中で消したい本能的な欲求や、切実な悩みがあるとき。
「お金を払いたくなる6分野」は財布が大きく痛みが深い**市場の地図**、「人がお金を払う13の欲望」は**誰が何に払うかの一覧**。6分野で市場の大きさを見て、13欲望で具体的な買い手を決める。

## 1. 6分野と13欲望の対応

| お金を払いたくなる6分野 | 対応する欲望（番号は§2） | 根っこにある本能 |
|---|---|---|
| ①美を追求する女性のお金 | 2 美貌 | 選ばれたい・老いと比較への不安 |
| ②スケベな男が払うお金 | 1 性欲 | 選ばれたい・孤独を消したい |
| ③お金持ちのお金 | 8 資産防衛・6 時間・12 丸投げ | 持っているものを失いたくない |
| ④一気にお金持ちになろうとする貧乏なお金 | 10 一発逆転・13 自由 | 今の状況から抜け出したい |
| ⑤年寄りの健康のお金 | 4 健康 | 衰え・病気・家族の負担になる恐れ |
| ⑥子どもの教育のお金 | 3 子どもの未来 | 子を守りたい・取り残させたくない |
| （6分野の外にある欲望） | 5 推し・7 ラク・9 承認・11 プロテイン | つながり・省エネ・認められたい・強くなりたい |

6分野に入る市場は、痛みが深く、払う金額も大きい。そのぶん競合も多く、法律の規制も厚い（§4）。

## 3. 診断の手順（本音と建前）

1. **払う人と使う人を分ける。** 子ども向けの商品は親が払い、親が選ぶ。SNSで話しかけるのは払う人。
2. **本音を1つ選ぶ。** 13欲望のどれで、何の痛みを消すのか。
3. **建前を1つ選ぶ。** 買ったことを家族や同僚に説明できる理由。人は本音で欲しくなり、建前で買う決心をする。
4. **本音は場面で、建前は言葉で。** 本音をそのまま書くと、反発されたり（「ラクしたい親」「モテたい男」）、規約や法律に触れたり（性欲・一発逆転・健康効果）する。本音は「夕飯を作っている5分」「満員電車の朝」のような場面で見せ、言葉にするのは建前にする。
5. **主欲望は1つ、副は2つまで。** それ以上は旗（何の人か）がぶれる。
6. **除外する欲望を理由つきで書く。** 刺さるけれど、旗・信用・法律とぶつかるものは使わない。

| 貧乏寄り | 塾に行かせられない引け目 | 家でも楽しく考える時間を | 割引（無料・低価格）、近道（1日5分）、親近感（同じ親として） |
| 富裕寄り | 確実に良い進路へ進ませたい | 本物の体験・個別の関わり | 確実性（実績と条件）、権威（指導者の経歴）、主導権（選べるコース） |

## 4. 痛みが深い市場ほど守る線

一発逆転・健康・美容・教育は、困っている人ほど強く反応する。そこに煽りの強い言葉を当てると短期では売れるが、返金・炎上・行政処分で信用が先に尽きる。このスキルは「痛みの深さ」を**需要の見積もり**に使い、**煽りの強さの根拠**には使わない。

- 収入・効果・合格を断言しない。書くなら根拠と、典型的な結果（成功例だけでなく）を示す。
- 期限・在庫・値引きは、実態があるときだけ書く。
- 体験談は実在の人の、同意を取ったものだけ。捏造は、それらしいほど重い。
- 高額の商品は、入口で無料の価値を十分に渡してから案内する。返金・解約の条件は先に書く。
- 18歳未満・高齢者・生活に困っている人に向けた設計は、とくに慎重に。子どもには直接売らず、親に話す。
