# ③ ニンジャ夜明け隊 RPG：詳細設計書 v2.0

「② ニンジャ夜明け隊（協力防衛・1回6分）」を、**コマンド式のRPG** として設計から作り直した版です。
CryptoNinja（CC0・Ninja DAO）の39体を使った個人制作の非公式ファンゲームです。物語・技・セリフはゲームの創作で、公式の設定ではありません。

---

## 0. 作り変えの理由

②を遊んで「面白くない」となった原因を、次のように考えました。

| ②でつまずいた点 | RPG版での答え |
|---|---|
| 自分が主役でない（3つの役割の1つ。39体は師匠・依頼人の脇役） | **39人全員を仲間にして、自分で動かせる**。仲間集めを遊びの中心にする |
| 物語と目的が薄い（毎回同じ里を守るだけ） | **5章の物語**。かけらを1つ取り戻すたびに空が明るくなる（進んだことが目に見える） |
| 成長が見えにくい（強化は1試合の中だけ） | レベル・新しい忍術・武器の鍛錬・お守り。**強くなった手ごたえ**を毎回返す |
| 反射神経の操作と、NPCまかせの部分が多い | **自分のペースで考えるターン制**。考えている間は時間が止まる |
| ルールが多いのに、気持ちよさの芯がない | 戦いの芯は1つ：**弱点を突いて「崩す」→印を重ねて大技**。分かりやすく、気持ちいい |

## 1. 概要

| 項目 | 内容 |
|---|---|
| タイトル | ニンジャ夜明け隊 〜明けない夜と39人の忍〜 |
| ジャンル | コマンド式RPG（ターン制）＋探索＋仲間集め |
| 対象 | 小学生（漢字にふりがな不要の言葉づかい）〜大人 |
| 遊ぶ時間 | 1回15〜30分（どこでもセーブ）。物語の最後まで数時間が目安（試作版で調整中） |
| 端末 | スマホ（縦・横）・タブレット・PC（キーボード／マウス） |
| お金 | 課金・ガチャ・スタミナなし。プレイ画面に広告なし（サイトの方針） |
| 通信 | なし。記録は端末の中だけ |

### 3つの柱

1. **39人の仲間集め** — 全員が仲間になる。1人ひとりに、公式の忍術・武器をもとにした技と、加入のお話がある。仲間帳に「どこで会えるか」のヒントが出る。
2. **崩しと印の戦い** — 弱点の型で当てると妖怪の「構え」が減り、0で「崩し」。崩れた相手には大ダメージ。ためた「印（いん）」を重ねて、ここぞで大技。順番が見えるので先を読める。
3. **忍術で開く探索** — 仲間の術で、大岩を押す・隠し道を見る・霧を晴らす・岩壁をこわす。仲間が増えるほど行ける場所が広がる。

＋ **夜明けの演出**：暁のかけらを取り戻すたびに、空・町・戦いの背景が少しずつ明るくなる。

## 3. 物語

### あらすじ

ある晩、天の社にある「暁の鐘」が、黒い大鴉の妖怪「夜鴉（よがらす）」に割られた。鐘のかけら5つは各地に散り、それから夜が明けなくなった。夜のあいだだけ力を増す妖怪たちが、里をおびやかしている。
甲賀の里の見習い忍者（主人公）は、長老の岩爺から旅を任され、孫の咲耶と一緒に出発する。行く先々で忍たちと出会い、かけらを取り戻して、夜明けを取り戻す。

- 黒幕「夜鴉」とその手下「影法師」は、このゲームの創作の妖怪です（公式のキャラクターを悪者にしない）。
- 風魔の忍たちは、はじめは「かけらを奪いに来た」とかんちがいして立ちはだかるが、話せば分かる（アトザは人情派）。

## 6. 戦闘

### 6.1 流れ

- **ラウンド制**。ラウンドのはじめに「すばやさ」で順番が決まる。画面の上に、**今のラウンドと次のラウンドの順番**が並ぶ。
- 自分の仲間の番が来たら命令をえらぶ。**考えている間は時間が止まる**。
- 前列4人で戦う。隊列の5〜8番は「控え」。

### 6.2 命令

| 命令 | 内容 |
|---|---|
| こうげき | 武器の型で1回攻撃（印で回数が増える） |
| 忍術 | 術力（MP）を使う技。攻撃・回復・強化・弱体・見破り |
| 道具 | 薬・投げ物（型つき）・見破りの巻 など |
| 防御 | 受けるダメージ半分。次の番に印+1 |
| 交代 | 控えと入れかわる（入った仲間は次のラウンドから動く） |
| 逃げる | 成功しやすい（ボス戦では使えない） |

### 6.3 攻撃の型（8つ）

**斬・打・射・火・水・雷・風・光**。仲間の「こうげき」は武器の型、忍術はそれぞれの型。妖怪には1〜3個の弱点と、効きにくい型（耐性）がある。

### 6.4 構えと崩し（戦いの芯）

- 妖怪には「構え」の数字がある（雑魚2〜7、ボス10〜20）。
- **弱点の型で当てるたびに構えが1減る**（多段攻撃は回数ぶん減る）。
- 構えが0になると **「崩し！」**：その妖怪は、今のラウンドと次のラウンドの番がとぶ。崩れている間は受けるダメージが **1.6倍**。次のラウンドの終わりに構えが元に戻る。
- ボスが「力をためている」ときに崩すと、**大技を止められる**。
- 弱点は最初「？」。当てるか、ハヤテの「鷹の目」や道具「見破りの巻」で分かる。分かった弱点は**妖怪図鑑に残り、次の戦いでは最初から見える**。

### 6.5 印（いん）

- 1人0〜5個。戦闘のはじめに1個。**自分の番のはじめに+1**（前の番で印を使ったときは増えない）。
- 命令の前に **1〜3個つかって強くする**：

| 命令 | 印1 | 印2 | 印3 |
|---|---|---|---|
| こうげき | 2回 | 3回 | 4回 |
| 攻撃の忍術 | 威力1.6倍 | 2.2倍 | 2.8倍（回数で当てる術は回数+1／+2／+3） |
| 回復の忍術 | 1.5倍 | 2倍 | 2.5倍 |
| 強化・弱体 | 続くターン+1 | +2 | +3 |

- 「回数が増える」＝ 弱点なら構えを一気に削れる。**崩す → 崩れた相手に印3の大技**、が気持ちよさの山場。

### 6.6 絆ゲージと絆技

- 隊で共有するゲージ（0〜100）。弱点+5（1回ごと）、崩し+15、妖怪を倒す+8、仲間が倒れる+10、回復+3。
- 満タンで **絆技**：組み合わせの2人が前列にそろっていれば、**2人の特別な技**（公式イラストのカットイン）。そろっていなければ **総がかり**（前列全員が自分の型で1回ずつ攻撃）。

| 絆技 | 2人 | 効果（初期案） |
|---|---|---|
| 双子口寄せ・紅白狐 | 咲耶＋狐白 | 風と斬の全体攻撃。構えを2ずつ削る |
| 兄弟豪打 | アトザ＋アウン | 打の特大単体 |
| 親子結界 | 結＋令 | 全員回復＋守り↑ |
| 虹の絵巻 | イチヤ＋ネム | 光の全体攻撃＋全員の印+1 |
| 兎と狐の大合戦 | 於兎＋宇迦 | 打と火のランダム8回 |
| 狐姉妹・九尾飯綱 | 宇迦＋イズナ | 火と風の全体攻撃 |
| 猫の目・妖刀 | 猫又＋久遠 | 斬の単体・必ず会心 |
| 団子と野アザミ | 餡音＋紫苑 | 敵全体を怯ませる＋斬3回 |
| 風魔の毒閃 | 呂屯＋断 | 光の全体攻撃＋毒 |

| 天と根の灯 | サットヴァ＋ササガネ | 全員全回復＋倒れた仲間も起きる |
| 暁の継承 | 主人公＋刃 | 光と火の特大全体 |

### 6.7 状態

| 状態 | 内容 |
|---|---|
| 毒 | 自分の番のはじめに最大HPの8%を失う（4ターン） |
| 眠り | 2ターン動けない。攻撃を受けると起きる |
| 封印 | 3ターン忍術が使えない |
| 怯み | 次の番が1回とぶ |
| 強化・弱体 | 攻撃・守り・すばやさを ×1.3／×0.75（3ターン） |
| その他 | かばう・反撃の構え・再生（毎ターン回復） |

### 6.8 勝ち負け

- 勝ち：経験値（**仲間全員に同じだけ**）・両・落とし物。倒れた仲間は戦闘後にHP1で起きる。
- 前列全員が倒れたら、**控えが1回だけかけつける**。
- それでも全員倒れたら、**「戦闘の前からやり直す」か「最後の記録から」** をえらぶ（失うものはない）。
- **おまかせ**（自動で戦う：分かっている弱点を突く・危ないときは回復）と **はやい**（演出2倍速）。

## 10. 数値（初期値・試作で調整）

| 項目 | 式・値 |
|---|---|
| 物理ダメージ | 攻撃 × 威力/100 × 120/(120＋守り) × 乱数(0.92〜1.08) |
| 忍術ダメージ | 忍術 × 威力/100 × 120/(120＋術守り) × 乱数 |
| 倍率 | 弱点×1.3（構え−1）／耐性×0.5（構えは減らない）／崩れ中×1.6／会心×1.5（会心率 4%＋運/5%） |
| 回復 | 忍術 × 威力/100 × 乱数 |

| 戦闘の長さ | 雑魚：はじめて会う相手でも3〜5ラウンド。ボス：8〜14ラウンド |

## 13. 受け入れ基準

1. 序章から終章のボスまで、**自動で遊ぶテストが最後までたどり着く**（行き止まり・進めなくなる状態がない）。
2. **39人全員が仲間にできる**（自動テストで全員の加入イベントを通す）。
3. 弱点・構え・崩し・印・絆技・状態・控えのかけつけ・やり直しが、決めた通りに動く（判定のテスト）。
4. 同じ乱数の種なら、戦闘の結果が同じになる。
5. 保存して読みこむと、場所・仲間・道具・旗・図鑑・開けた宝箱が元に戻る。お金と道具の数は負にならない。
6. すべての地図で、出口・人・宝箱・障害物が歩ける場所にあり、行き先の地図と位置が正しい。
7. 章ごとの雑魚戦は、目安のレベルで勝てて、はじめての相手でも3〜5ラウンドで終わる（試算）。ボスは目安のレベルで勝てる。
8. スマホ縦（360×640〜）・横・PC（1280×720〜）で、最後まで操作でき、エラーが出ない。
9. 読みこみ後、最初の戦いまで2分以内（オープニングを飛ばせば1分以内）。
