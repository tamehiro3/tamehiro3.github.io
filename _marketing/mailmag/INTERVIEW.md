# 体験談の聞き取りシート（号ごと）

- 版: 2026-10-03（初版）
- 使い方: 号を書く前に、その号の質問だけに答える（一度に全部答えなくていい）。Typeless で話したものをそのまま貼れば、Claude が「前 → きっかけ → 今」の3行に整えて `BLUEPRINT.md` §5 に入れ、本文の下書きに使う
- 上手に答えるコツ: きれいにまとめなくていい。**数字・固有名詞・そのときの気持ち**が入っていれば、それが一番の材料になる（文章ガイド §1「具体性」、§7「想定読者は過去の自分」）
- 答えた内容のうち、本文に使うのは本人が「出してよい」と言った部分だけ

## 書かないでほしいもの（安全のため）

- ウォレットのアドレス・秘密鍵・復元フレーズ（シードフレーズ）・取引所のアカウント名。**どんな形でも貼らない**
- 保有している暗号資産の量や金額（狙われる理由になる。設計図の「稼いだ金額を出さない」線引きとも同じ）
- 家族・知人など、本人以外が特定される情報

## 聞く順番

Why 回（1〜5号）は本人の価値観の変化が中心なので、ここが一番大事。How 回・Keep 回の質問は、その号の前に追加で聞く。

### 第1号（開講宣言・リストマーケティング）

1. メールやリストの価値に気づく前、SNSのフォロワーや「いいね」をどう見ていた？
2. 考えが変わったきっかけは？（出来事・人・本・明鏡のどこか。日付や場面が分かれば）
3. 今はどう考えている？ それで実際に何を変えた？
4. 恥ずかしい失敗や遠回りはある？（アイスブレイクに使う）
5. このメルマガで、読者に一番動いてほしいことは何？

### 第2号（ビットコイン）

1. ビットコインを知った頃、どう見ていた？（値段・怪しさ・投機など、正直に）
2. 見方が変わったきっかけは？
3. 今は何だと思っている？ 生活や考え方で何が変わった？
4. 怖かったこと・失敗したことは？（金額は書かない）

### 第3号（DeFi）

1. DeFiを触る前のイメージは？
2. 初めて触ったときに驚いたこと・怖かったことは？
3. 今、DeFiとどう付き合っている？ 自分ルールはある？
4. 失敗・ヒヤッとした経験は？（金額やサービス名は、出してよいかも一緒に教えて）

### 第4号（Claude Code で作るAIゲーム）

1. ゲームを「作る側」になる前、自分にできると思っていた？
2. Claude Code で最初に作ったものは？ いつ頃？ 何に何日かかった？
3. しのびのゲーム工房のゲームは、どれを Claude Code で作った？（事実台帳に書いてから本文で使う）
4. 作る側に回って、価値観で一番変わったことは？

### 第5号（Codex で作るアプリ）

1. 「アプリは買うもの」と思っていた頃、どんな道具に不満があった？
2. Codex で最初に作った（作ろうとした）ものは？
3. Claude Code との使い分けは、実感としてどう？
4. 自分の道具を作れるようになって、働き方で何が変わった？
