# 事実台帳（OFFER_FACTS）— SNS投稿で使ってよい事実

投稿に書く数字・実績・特徴は、**この台帳にあるものだけ**を使います。
ここにない事実を書きたいときは、先に出典つきでこの台帳へ追記してから投稿します。

- 機械検品は投稿文の数字（例: `10種類` `5分`）をこのファイルの本文と照合し、見つからない数字に「要確認」を付けます。
- 出典はすべてこのリポジトリ内のページです。ページの記述を変えたら、この台帳も同じコミットで直します。

## 言ってはいけないこと（事実と矛盾する・根拠がない）

| 表現 | 理由 |
|---|---|
| 「広告なし」「広告ゼロ」 | Google AdSense を利用している（privacy.html 3章）。事実と矛盾 |
| 「CNP公式」「CryptoNinja公式」 | 個人制作。公式と誤認させない |
| 脳の若返り・認知症予防・学力や成績が上がる など効果の断言 | 裏づけとなる試験や調査がない（景品表示法の不実証広告規制・薬機法の領域） |
| 「No.1」「日本一」「業界初」など最上級 | 裏づけとなる調査がない |
| 「期間限定」「残りわずか」「先着」 | 無料でいつでも遊べるので、希少性の実態がない |
| プレイ人数・ダウンロード数・評価の数字 | 現在アクセス解析を入れていない（privacy.html 4章）ため、出典になる数字がない |
