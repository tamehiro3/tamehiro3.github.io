# ニンジャ夜明け隊（試作版）

役割のちがう見習い忍者で力を合わせ、夜明けまで里の結界を守る、短時間の協力ゲームです。
設計書「② ニンジャ夜明け隊：詳細設計書 v1.0」のうち、**スマホ初期版（1人＋NPC2人・約6分）** をブラウザで作った試作です。

- 遊ぶ: https://tamehiro3.github.io/ninja-yoake-tai/
- 遊び方・保護者の方へ: `about.html`
- キャラクターシート（39体）: `../ninja-sato-life/sheets/`（ニンジャ里ライフと共有）

CryptoNinja（CC0・Ninja DAO）のキャラクターを使った個人制作の非公式ファンゲームです。役割・忍術・セリフ・支援の効果はゲームの創作で、公式の設定や能力ではありません。

## 動かし方

ライブラリなしの HTML / JavaScript だけで動きます（ビルド不要）。キャラクターの絵は `../ninja-sato-life/art.js`・`chars.js` を読みこむので、**リポジトリの直下から** サーバーを立ててください。

```sh
# リポジトリの直下で
python3 -m http.server 8765
# → http://127.0.0.1:8765/ninja-yoake-tai/
```

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面（タイトル・広場・編成・戦闘中の表示・結果・パネル） |
| `data.js` | 数値と中身（基本値・1試合の流れ・役割・忍術12・罠・補給・強化・敵・地図・承認済みの任務4つ・敵の組み合わせ・支援・目標・難易度・報酬・修行課題・外見）。任務監督はここの ID を選ぶだけ |
| `sim.js` | 試合の判定（サーバー役）。MatchState、ダメージ・再使用・素材・救助・勝敗・報酬の元になる結果を1回だけ確定。画面に依存しないので、サーバーへ移しても同じ判定ができる |
| `ai.js` | 仲間の見習い（NPC）の動き。生成AIは使わない固定ロジック。人と同じ「入力の意図」を出す |
| `director.js` | 任務監督（次の任務の提案）。標準はルール。AI 接続は試験機能（https・8秒・検証・1日3回・キャッシュ・ルールに戻る） |
| `progress.js` | 記録と報酬（session_id ごとに1回・放置の判定・修行課題・絆・週の任務・計測） |
| `lines.js` | 39体のセリフ（師匠の助言・依頼・支援・勝ち負け・絆） |
| `render.js` | キャンバスの描画（地面・忍者の絵の画像化・妖怪・予告・術・夜明けの光・小さな地図） |
| `input.js` / `audio.js` | 入力（タッチのスティックとボタン・キーボードとマウス）／音（WebAudio で合成） |
| `tutorial.js` | 最初の任務（移動・攻撃・回避 → 素材と罠 → 小さな襲撃と連携 → 救助する・される → 小ボス → 忍術えらび） |
| `ui.js` / `game.js` | 画面と流れ（広場 → 編成 → 出撃 → 結果 → 再出撃）・毎フレームの処理 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面に追加・オフライン |
| `tools/test_sim.mjs` | 設計書 §12 の受入テスト |
| `tools/balance.mjs` | 勝率のめやす（NPC だけで何試合も回す。開発用） |

## テスト

```sh
node ninja-yoake-tai/tools/test_sim.mjs    # 結果: 127 件合格 / 0 件不合格
node ninja-yoake-tai/tools/balance.mjs 16 normal
```

受入テストでは、§12 の項目（連打・速度改変・報酬の再送で得をしない／ボスと結界の同時破壊・全員ダウンの優先順位を固定して結果を二重に確定しない／切断・再接続・NPC の引き継ぎ／役割が重なっても標準難易度を攻略できる／AI の提案の予算超過・無効な配置・通信失敗・時間切れで通常の提案に戻る／敵が多いときの処理の重さ）と、救助・連携・盾持ち・罠・強化・支援・報酬・週の任務・最初の任務を確かめます。

## 更新するとき

- 中身を変えたら `index.html` の `?v=1` と `sw.js` の `CACHE` / `V` の番号を上げる
- `../ninja-sato-life/art.js`・`chars.js` を読むときの `?v=2` は、ニンジャ里ライフ側の番号に合わせる
- 数値を変えたら `tools/test_sim.mjs` と `tools/balance.mjs` を回す

|---|---|

| 役割3つ（一閃30・8秒／盾HP120・8秒・20秒／範囲回復25・15秒）・重複可・補給設備 | ある。補給所は薬湯・護り札・焙烙玉（足りない役割をおぎなう） |
| 救助3秒・被弾で停止・ダウン中のピン・課金なしの蘇生 | ある。全員ダウンのときは5秒の救済時間（結界にたどり着いた1人だけ起き上がれる） |
| 忍術6つ・2枠・襲撃間に3候補から強化・連携と共通アイコン | ある。別の型6つを修行札150で解放（強さでなく選択肢が増える） |
| 地図（結界・進入路2・採集3・罠6）・敵4種 | ある。妖怪はかわいい見た目で、しずめると光になって消える |
| 報酬（勝利100・敗北は突破襲撃ごと20・上限60・150で解放）・放置の判定 | ある。session_id ごとに1回だけ |
| カスタマイズ・修行課題・週の固定任務 | ある。外見は強さに関係しない。週の任務はランキングなし |
| 画面（広場→編成→出撃→戦闘→結果→再出撃）・合図3種・PC とタッチ・標的補助 | ある |
