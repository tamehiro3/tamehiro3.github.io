# ⑨ 投稿用キャプション — ep25（【PR】いちばん使ってる教材「明鏡」・作り直し版）

動画：`episodes/ep25/out/ep25.mp4`

この回は**広告（PR）**です。プロフィールに置くBrainの紹介リンクから買われると、ためひろさんに紹介報酬が入ります。広告だと分かるようにしているのは次の4か所です。
- 画面：0秒目から最後まで、左上に「PR・紹介報酬あり」のラベル（濃紺の「PR」＋白地の「紹介報酬あり」）
- 声：2〜3文目
- 見出し：2文目に「これはPRやで」
- キャプション：1行目

## 投稿前のチェック
- [ ] **ためひろさん本人に確かめる**
  - いちばん使っている教材は明鏡か（「Claude Codeの教科書」など、イケハヤさんの別の教材ではないか）
  - 台本の出だしの型と、商品作りと集客の流れは、明鏡から学んだことを使っているか
  - 違っていたら、4文目と8〜10文目、14文目を作り直す
- [ ] **Brainの販売ページを自分の目で開いて確かめる**（どれも検索結果の要約で確認しただけ）
  - 値段が **29,800円** か、**税込み**か。投稿前に変わっていたら11文目を作り直す。投稿後に変わった場合はキャプションだけ直せばよい（動画は「26年10月時点」と言っているので残せる）
  - 受付が **毎月1日〜5日** か
  - 返金は **原則なし** か
  - 紹介リンクの行き先が「明鏡」のページか
- [ ] **「数億円」の出どころを自分の目で確かめる**（7文目「本人いわく、イケハヤさんは過去に数億円売った人や」）
  - 根拠はイケハヤさん本人のnote「情報商材で5億円稼いだイケハヤが考える、これからの稼ぎ方」（https://note.com/ihayato/n/nf46a938f7acd ）。2016〜2021年の有料コンテンツとオンラインサロンの売上の合計で、約5億円と書かれている（本人の申告。売上で、利益ではない）
  - 今も毎年数億円売っている、とは言わない。本人は2026年1〜7月のBrainの売上を「1億円超え」としつつ、「今年4月までは会社が潰れる寸前だった」とも書いている（https://ihayato.substack.com/p/brain1brain ）
- [ ] **「必須」は、ためひろさん本人にとっての話として言っている**（14文目「自分でお金をつくる生き方を目指す僕には必須やねん」。テロップの強調は【僕には】、見出しは「僕の場合は」）
  - キャプションやコメントで「みんな必須」「これがないと無理」に広げない
  - すぐ後の15文目で「【収入の約束】はない」と、同じくらい目立つ形で打ち消している
  - 「お金をつくる」と「必須」が同じ文にあることで、TikTokの「すぐに稼げる」系の宣伝の禁止や、景品表示法の効果の表示に近く見えるおそれは残る。気になる場合は14文目を「自分で商売を回したい【僕には】／必須の教材や」に替えられる
- [ ] **無料の第1章は案内していない**：公式の学習サイト（meikyo.ikedahayato.com）の無料の第1章が、有料の明鏡の第1章と同じ中身かは確かめられていない（未確認）。目次で照らし合わせて同じと確かめられたら、キャプションに「第1章は公式の学習サイト（無料会員）で読める」を足してよい
- [ ] **出す日**：買えるのは毎月1日〜5日なので、その少し前〜期間中に出すと、見た人がすぐ確かめられる。ただし受付の最終日（毎月5日）には出さない。キャプションやコメントで締め切りを強調して急がせることもしない
- [ ] **プロフィールのリンク**のそばに「紹介リンク（紹介報酬あり）」と書く
  - TikTokは、フォロワー数やアカウントの種類によってリンク欄が出ないことがあるとされる（未確認）
  - 欄が出ないなら、TikTokでは出さないか、16文目を作り直す
- [ ] **本番の声で作り直して、耳で確かめる**：`python tools/make.py ep25 --engine fal`
  - 2文目の「PR」が「ピーアール」とはっきり聞こえて、6秒以内に入っているか。英語読みになっていたら、2文目の読みを「…この動画は、／ぴーあーるやで」にして作り直す
  - 3文目「紹介料がはいる」（「いる」に聞こえないか）、4文目「めいきょう」、6文目「おもてる」
  - 7文目の「数億円」、11文目の年と値段、13文目の「まいつき・ついたち・いつか」
- [ ] 書き出した動画を各アプリの投稿プレビューで開いて、左上の「PR・紹介報酬あり」が上部のボタンや見出しで隠れていないか確かめる
- [ ] 各アプリの**広告の設定**（下の各SNSの欄）をオンにする
- [ ] コメントで「稼げる？」と聞かれたときの返し方の例：「収入の約束はないで。読む時間も要るから、販売ページをよう読んでな」

### 言わない・書かないこと（コメント欄も同じ）
- 「稼げる」「月○万」「誰でも」「すぐ」「最強」「No.1」「人生変わる」
- 「今だけ」「もうすぐ締め切り」「今月中に」「次の受付は○日から」「値上げ前に急いで」
- 値上げ予定（49,800円）：公式サイトで予定は確認できているが、急がせる言い方になり、二重価格にも見えるため書かない
- 「10万円まで上がる」という話：確認できていない
- 「案件ちゃうで」「第三者の正直な感想」「ステマちゃう」：紹介報酬がある以上、広告として扱う
- 「イケハヤさん公認」「コラボ」「イケハヤさんが教えてくれる」：提携や直接の指導があるように見せない。イケハヤさんの写真・ロゴ・販売ページの画像も使わない
- 「買うたらあなたも紹介で稼げる」：紹介制度そのものを勧めない
- 「AIに読み込ませてOK」：公式の規約で確かめられていない
- 「イケハヤさんは毎年数億円稼いでる」「数億円稼げる方法が学べる」：本人の発信は過去の累計の売上で、利益でも、視聴者の収入の話でもない
- 「お金をつくる生き方には必須（誰にとっても）」「僕の感想です（だけで済ませる）」：必須は、ためひろさん本人の話として言い、すぐ後に具体的な打ち消し（収入の約束はない）を置く
- 「教材に台本のテンプレが入ってる」：確認できていない。ためひろさんが学んだことを自分の台本に使っている、という言い方にとどめる
