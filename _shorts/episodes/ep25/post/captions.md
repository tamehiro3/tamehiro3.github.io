# ⑨ 投稿用キャプション — ep25（【PR】いちばん使ってる教材「明鏡」）

動画：`episodes/ep25/out/ep25.mp4`

この回は**広告（PR）**です。プロフィールに置くBrainの紹介リンクから買われると、ためひろさんに紹介報酬が入ります。動画の画面（0秒目から最後まで左上に「PR・紹介報酬あり」）、声（2〜3文目）、キャプションの1行目の3か所で広告だと分かるようにしています。

## 投稿前のチェック
- [ ] **出す日**：買えるのは毎月1日〜5日だけ（10月から）。次の受付は **11/1（日）〜11/5（木）23:59**。10/31〜11/1に出すと、見た人がすぐ確かめられる。今すぐ出す場合も、動画の中で「毎月1日から5日だけ」と言っているので、内容としては問題ない
- [ ] Brainの販売ページを自分の目で開いて、次を確かめる（どれも検索結果の要約で確認しただけ）
  - 値段が **29,800円** のままか（変わっていたら12文目とキャプションを直す）
  - 受付が **毎月1日〜5日** のままか
  - 返金は **原則なし** か
  - 紹介リンクの行き先が「明鏡」のページになっているか
- [ ] 公式の学習サイト（https://meikyo.ikedahayato.com/ ）で、**第1章が無料で読める**ままか確かめる
- [ ] **プロフィールのリンク**のそばに「紹介リンク（紹介報酬あり）」と書く
  - TikTokは、フォロワー数やアカウントの種類によってプロフィールにリンク欄が出ないことがあるとされる（未確認）。欄が出ないなら、TikTokでは出さないか、言い方を変える
- [ ] 各アプリの**広告の設定**（下の各SNSの欄）をオンにする
- [ ] コメントで「稼げる？」と聞かれても、収入の話はしない。返す文の例：「収入の約束はないで。合う合わんもあるから、無料の第1章で確かめてな」

### 言わない・書かないこと
- 「稼げる」「月○万」「誰でも」「すぐ」「最強」「No.1」「人生変わる」「今だけ」「値上げ前に急いで」
- 値上げ予定（49,800円など）や「10万円まで上がる」という話。急がせる言い方になり、確認もできていない
- 「案件ちゃうで」「第三者の正直な感想」「ステマちゃう」。紹介報酬がある以上、広告として扱う
- 「イケハヤさん公認」「コラボ」。提携しているように見せない。イケハヤさんの写真・ロゴ・販売ページの画像も使わない
- 「買うたらあなたも紹介で稼げる」。紹介制度そのものを勧めない
- 「AIに読み込ませてOK」。公式の規約で確かめられていない
