# ⑨ 投稿用キャプション — ep25（【PR】いちばん使ってる教材「明鏡」）

動画：`episodes/ep25/out/ep25.mp4`

この回は**広告（PR）**です。プロフィールに置くBrainの紹介リンクから買われると、ためひろさんに紹介報酬が入ります。広告だと分かるようにしているのは次の3か所です。
- 画面：0秒目から最後まで、左上に「PR｜紹介報酬あり」
- 声：2〜3文目
- キャプション：1行目

## 投稿前のチェック
- [ ] **ためひろさん本人に確かめる**
  - いちばん使っている教材は明鏡か（「Claude Codeの教科書」など、イケハヤさんの別の教材ではないか）
  - 台本の冒頭の型と、動画づくりの流れは、明鏡から取り入れたものか
  - 違っていたら、6〜9文目と16文目を作り直す
- [ ] **Brainの販売ページを自分の目で開いて確かめる**（どれも検索結果の要約で確認しただけ）
  - 値段が **29,800円** か。投稿前に変わっていたら、12文目を作り直す。投稿後に変わった場合はキャプションだけ直せばよい（動画は「10月時点」と言っているので残せる）
  - 受付が **毎月1日〜5日** か
  - 返金は **原則なし** か
  - 紹介リンクの行き先が「明鏡」のページか
- [ ] 公式の学習サイト（https://meikyo.ikedahayato.com/ ）で、**無料会員になると第1章が読める**ままか確かめる
- [ ] **出す日**：買えるのは毎月1日〜5日なので、その少し前〜期間中に出すと、見た人がすぐ確かめられる。ただ、キャプションやコメントで締め切りを強調して急がせることはしない
- [ ] **プロフィールのリンク**のそばに「紹介リンク（紹介報酬あり）」と書く
  - TikTokは、フォロワー数やアカウントの種類によってリンク欄が出ないことがあるとされる（未確認）
  - 欄が出ないなら、TikTokでは出さないか、17文目を作り直す
- [ ] **本番の声で作り直して確かめる**：`python tools/make.py ep25 --engine fal`
  - 2文目の「PR」が「ピーアール」とはっきり聞こえて、6秒以内に入っているか
  - 12文目の値段、14文目の日付が正しく聞こえるか
  - 英語読みになっていたら、2文目の読みを「…この動画は／ぴーあーるやで」にして作り直す
- [ ] 書き出した動画を各アプリの投稿プレビューで開いて、左上の「PR｜紹介報酬あり」が上部のボタンや見出しで隠れていないか確かめる
- [ ] 各アプリの**広告の設定**（下の各SNSの欄）をオンにする
- [ ] コメントで「稼げる？」と聞かれたときの返し方の例：「収入の約束はないで。読む時間も要るから、公式の無料の第1章で確かめてな」

### 言わない・書かないこと（コメント欄も同じ）
- 「稼げる」「月○万」「誰でも」「すぐ」「最強」「No.1」「人生変わる」
- 「今だけ」「もうすぐ締め切り」「今月中に」「次の受付は○日から」「値上げ前に急いで」
- 値上げ予定（49,800円）：公式サイトで予定は確認できているが、急がせる言い方になり、二重価格にも見えるため書かない
- 「10万円まで上がる」という話：確認できていない
- 「案件ちゃうで」「第三者の正直な感想」「ステマちゃう」：紹介報酬がある以上、広告として扱う
- 「イケハヤさん公認」「コラボ」：提携しているように見せない。イケハヤさんの写真・ロゴ・販売ページの画像も使わない
- 「買うたらあなたも紹介で稼げる」：紹介制度そのものを勧めない
- 「AIに読み込ませてOK」：公式の規約で確かめられていない
- 「教材に台本のテンプレが入ってる」：確認できていない。ためひろさんが学んだことを自分の台本に使っている、という言い方にとどめる

- 広告の設定：投稿画面の「コンテンツの開示と広告」で「商用コンテンツを開示」をオン
  - 他社の商品の紹介なので「ブランドコンテンツ」が近いが、アプリの説明文を読んでから選ぶ
  - ブランドのタグ付けを求められて選べない場合も、開示はオフにしない
- AIラベル：「AI生成コンテンツ」をオン
- 注意：TikTokの広告の決まりでは「すぐに稼げる」系の宣伝が禁止と報じられている。キャプションに収入の話を足さない
