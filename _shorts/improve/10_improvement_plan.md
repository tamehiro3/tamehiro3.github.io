## 1. 計測のしかた（投稿の24時間後・72時間後・7日後）

`improve/metrics_template.csv` をコピーして `improve/metrics_ep01.csv` を作り、各アプリのインサイトから次の数字を写します。

| 列 | TikTok | Instagram リール | YouTube ショート |
|---|---|---|---|
| views | 動画の視聴数 | 再生数 | 視聴回数 |
| reach | — | リーチしたアカウント数 | — |
| avg_watch_sec | 平均視聴時間 | 平均再生時間 | 平均視聴時間 |
| hook_rate | 視聴維持率グラフの2〜3秒時点の値 | 維持率グラフの3秒時点の値 | 「スワイプされずに視聴」の割合 |
| completion_rate | 動画を最後まで視聴した割合 | （あれば） | 維持率グラフの最後の値 |
| likes / comments / shares / saves | そのまま | いいね・コメント・シェア・保存 | 高評価・コメント・共有 |
| sends | — | シェア（DMで送信）の数 | — |
| follows | 動画からのフォロワー | フォロー数 | 登録者の増加 |
| fyp_share | トラフィックソース「おすすめ」の割合 | 発見タブ・リール経由の割合 | ショートフィード経由の割合 |
| search_share | 「検索」の割合 | 検索経由の割合 | YouTube検索の割合 |

記入したら、次を実行します。

```
python3 tools/analyze.py improve/metrics_ep01.csv --out improve/analysis_ep01.md
```

弱い指標が、ファネルの上から（フック → 視聴 → 完了 → 拡散 → 反応）優先順に並び、次回の具体的な直し方が出ます。基準値は**目安（勘）**です。5〜10本たまったら、自分の中央値に置き換えてください。

## 2. 診断表（どの数字が弱いと、どこを直すか）

| 弱い数字 | アルゴリズム上の意味 | 直すところ（script.json の該当箇所） |
|---|---|---|
| 冒頭の維持（2〜3秒） | 最初の配信テストで「スワイプされた」と判定され、次の配信が止まる（YouTubeは「見られたか、スワイプされたか」が最初の関門） | 1文目を15文字以内に。1コマ目に「場面」か「結果」。カバーとキャプション1行目を問いかけにそろえる |
| 平均視聴率 | 最後まで見られず、おすすめに乗りにくい | 解決策を8秒以内に。同じ図解を4秒以上続けない。中だるみの文を削る |
| 完了率・再視聴 | ループが効いていない | 最後のコマ＝1コマ目にする。最後の文を冒頭への「つなぎ」に |
| おすすめ経由の割合 | 興味の分類に失敗している | キャプション・テロップに検索される言葉（ChatGPT、設定、使い方）を入れる。投稿時間を変える |
| シェア・送信 | 「誰かに送る理由」がない（Instagramは送信数が主要指標） | 「親に」「同僚に」と送る相手を名指しする |
| 保存 | 後で見返す理由がない | 手順を1枚の図に残す。キャプションに手順を書く |
| コメント | 返しやすいお題がない | キャプションに一言で答えられる質問やキーワード（「オフにした」） |
| フォロー | 次も見る理由がない | シリーズ名の固定、次回予告、プロフィールに投稿時間 |

## 3. 改善点の一覧

### 3-1. 投稿前にわかっていること（ep01 の軍配検品より）

| # | 改善点 | 根拠 | ep02 での対応 |
|---|---|---|---|
| 1 | **声を本人のクローン声にする**（最大のリスク） | 仮の合成音声は抑揚が機械的で、維持率を下げる | ③の条件がそろい次第、全話を差し替え（`voice_ref/README.md`） |
| 2 | 解決策の提示が遅い（16秒） | リサーチの構成テンプレは「8秒までに問題提起」 | **2文目（約4秒）で答えを出す** |
| 3 | 上半分が模式図で、実演感が弱い | 1位の動画は「実演・対決型」 | **会話が1文ずつ増える実演風のチャット画面** |
| 4 | 1コマ目が文字だけ | フックは「見る理由」（軍配 video.md） | **1コマ目に場面**（業者のひと言の吹き出し） |
| 5 | CTAが2つあった | 軍配 video.md「締めのCTAは1種類」 | ep01で修正済み。ep02も「親に送って」の1つだけ |
| 6 | 57秒（TikTokの収益化は1分以上） | Creator Rewards の条件 | ep02は59.9秒。61秒版は数字を見てから判断 |
| 7 | 本人の体験の一文が未確認 | 軍配「本人の声が要る箇所は本人の加筆なしに出荷しない」 | ep02の本人体験の文は入れていない。代わりに一般的な事実（不安だと言葉が出ない）で構成 |

### 3-2. 投稿後に数字で確かめること（仮説）

| 仮説 | 見る数字 | 採用する条件（目安） |
|---|---|---|
| 「場面」から入ると、冒頭の維持が上がる | ep01 と ep02 の冒頭の維持率 | ep02 が +5ポイント以上 |
| 答えを4秒で出すと、平均視聴率が上がる | 平均視聴率・維持率グラフの6〜16秒の落ち方 | ep02 のほうが落ち込みが小さい |
| 「親に送って」は送信・シェアを増やす | Instagram の送信率、TikTok のシェア率 | 送信率 1%以上 |
| 安全系のテーマは18〜24歳の女性にも届く（リサーチ4位の投稿者の発言） | 視聴者の年齢・性別 | そうなら、テーマ選びとハッシュタグを寄せる |
| 19時台の投稿が最適 | 24時間の視聴数（同条件で比較） | 3回以上の比較で判断 |
