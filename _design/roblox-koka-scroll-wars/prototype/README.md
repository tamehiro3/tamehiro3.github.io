# Roblox Studio で動く骨組み（試作）

設計図 [`../BLUEPRINT.md`](../BLUEPRINT.md) の「MVPの順番」の最初の2段、**蔵と昼夜と運搬 → 風魔の影**を、数値を小さくして Roblox Studio で試せる形にしたものです。コードはスクリプト2本だけで、地図も起動時に自動で組み立てます。

- 版: 2026-10-03（初版）
- 状態: **未動作確認**。この環境では Roblox を動かせないため、構文チェック（luaparse）だけ通しています。Studio で動かして直すところを見つけるのがこの試作の目的です
- 入っていないもの: セーブ（DataStore）、術合わせ、推理、課題カード、捕り札、身代わり札、罠、相棒。すべて設計図どおり次の段

## 1. 入れ方（5分）

1. Roblox Studio を開き、「Baseplate」テンプレートで新しい場所を作る
2. 画面右の「エクスプローラー」で **ServerScriptService** を右クリック → 「オブジェクトを挿入」→ **Script**。名前を `ServerMain` にする
3. 開いたスクリプトの中身を全部消し、[`ServerMain.server.lua`](ServerMain.server.lua) の中身を全部貼り付ける
4. **StarterPlayer → StarterPlayerScripts** を右クリック → 「オブジェクトを挿入」→ **LocalScript**。名前を `HUD` にする
5. 中身を全部消し、[`HUD.client.lua`](HUD.client.lua) の中身を全部貼り付ける
6. 上のメニュー「ゲーム設定」（または「ファイル → ゲーム設定」）→「場所」でサーバーの最大人数を **8** にする（蔵が8軒なので）
7. 「プレイ」ボタンで開始

うまく動けば、商店街（北側、スタート地点）に光る欠片が転がっていて、画面の上に「☀ 昼 3:00」のタイマーが出ます。

## 2. ひとりで試すこと（10分）

昼夜のサイクルは設計図どおり昼3分・夜1分30秒・猶予20秒です。短くしたいときは `ServerMain` の先頭 `CONFIG` の `DAY_SECONDS` などを変えてください（例: 昼60・夜45）。

| 順番 | やること | 期待する動き |
|---|---|---|
| 1 | 欠片に近づいて「拾う」 | 手持ちが 1/3 になる。4枚目は「手がいっぱい」 |
| 2 | 南へ歩き、自分の名前がついた蔵の棚（枠）で「棚」 | 欠片が棚に乗り、「毎分 ○小判」が増える。左上の表示と右上の小判が増えていく |
| 3 | 夜になるのを待つ（上のタイマー） | 空が暗くなる。「夜になった(1夜目)」の帯 |
| 4 | 夜の45秒目に「風魔の影が蔵の前に来た!」が出たら、戸口そばの青い板で「結界を張る」 | 2秒の詠唱のあと蔵が青く包まれ、「結界が風魔の影を退けた」 |
| 5 | もう一度夜を迎え、今度は結界を張らずに見る | 影がお守り以外の一番レアな欠片を1枚持って西へ帰る。「取り返しに行こう」の帯 |
| 6 | 西の「風魔の蔵」へ。黄色い帯（見張りの視線）を避けて、棚の「(縄)」の欠片で「棚」 | 取り返せる。帯に2秒入ると入口に戻される |
| 7 | 同じ夜に、風魔の蔵の「青」の欠片を「棚」で持ち出す | 速度が落ちる。夜明けの猶予20秒以内に自分の蔵の戸口をくぐると「運搬成立!」。間に合わないと風魔の蔵に戻る |
| 8 | 結界を張ってから蔵を離れてみる | 残り秒が3倍速で減る（15スタッド以上離れたとき） |

## 3. ふたり以上で試すこと

Studio の「テスト」タブ →「クライアントとサーバー」で人数を 2〜3 にして開始すると、別々の窓で複数のプレイヤーになれます。

- 夜に相手の棚から持ち出せるか（昼は「持ち出せるのは夜だけ」）
- 結界中の棚は「結界に阻まれた」になるか
- お守りの欠片（枠1）は「持ち出せない」になるか
- 持ち出された側に「⚠ ○の欠片が持ち出された!」が出るか
- 1晩に4枚目を持ち出そうとすると止まるか
- 蔵の中に相手がいる間は結界が張れないか（「先手で張るもの」）
- 相手が退出すると、その蔵が「空き蔵」に戻って棚が空になるか

## 4. ここで見たい「面白いか」の判断材料

設計図13章の数値を、手動で記録してください。

- 最初の60秒で欠片を棚に置けたか（目標: ほぼ全員）
- 「持ち出された」直後に嫌な気持ちで続ける気が失せるか、「取り返しに行こう」と思えるか
- 夜1分30秒は「守るか攻めるか」を迷う長さか、短すぎるか
- 風魔の蔵の見張りは、避けられる難しさか（2秒で見つかる設定）
- 風魔の影が来る45秒目は、結界を押す緊張感になっているか

## 5. 直す予定の順番（この試作の次）

1. 動作確認で見つかった不具合
2. 捕り札（運搬中の相手に当てると欠片が棚に戻る）と身代わり札
3. 罠2種（鳴子・落とし穴）
4. セーブ（ProfileStore）と「ログイン時の精算」
5. 術合わせ（言葉札2枚 → 効果表）。ここから AI が入る

## 6. 中身の地図（スクリプトを読む人向け）

`ServerMain` は番号つきの節に分かれています。

| 節 | 内容 |
|---|---|
| 0 | `CONFIG`（数値はここだけ） |
| 1 | 画面への通信（`State` / `Notify`） |
| 2 | 部品を作る道具（パーツ・名札・近接ボタン・レア度の抽選） |
| 3 | 地図の自動生成（商店街・蔵通り8軒・風魔の蔵） |
| 4 | プレイヤーの状態（手持ち・運搬中の数・小判） |
| 5 | 棚の欠片（見た目、空き枠、影が狙う枠、毎分収入） |
| 6 | 昼夜（夜明けの返却、自分の手持ちの自動配置、夜の開始） |
| 7 | 商店街に欠片が湧く |
| 8 | 棚の操作（置く・持ち出す・取り返す）と戸口の判定 |
| 9 | 結界（詠唱・侵入者チェック・離れると早く切れる） |
| 10 | 風魔の影（夜45秒目に結界のない蔵へ、壁をすり抜ける） |
| 11 | 見張り（往復と視線の判定、見つけたら入口へ戻す） |
| 12 | プレイヤーの出入り（蔵の割り当て・お守り・退出時の片づけ） |
| 13 | 時間を進めるループ（昼夜・結界・収入・湧き・影の出番・画面送信） |
