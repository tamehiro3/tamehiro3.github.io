# ② テーマ別 60秒台本（5本）

ルール
- 1文は20文字前後
- 1文目は視聴者への問いかけ
- 最後の一文で冒頭に戻るループ
- 「／」はテロップを切り替える声の区切り、【】は大きく・黄色で出す言葉
- 使わない言い回し：「重要」「ぜひ」「さらに」「これにより」「〜しましょう」「いかがでしたか」「解説します」など（qa.py で自動検査）
- 口調はためひろさんの話し方に合わせる（2026-09-26 本人確認）：「〜なんだよね」→「〜なんよ」、「〜しちゃダメ」→「〜したらあかんで」
- 1本の動画に入れるCTAは1つ（軍配 video.md §1）。コメント誘導はキャプション側に置く

各本の尺は音声合成の話速によって変わります。1本目は実測で約57秒です（仮の声、話速1.15）。
