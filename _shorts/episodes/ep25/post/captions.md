# ⑨ 投稿用キャプション — ep25（【PR】いちばん使ってる教材「明鏡」・紹介の仕組みと厳選した2つ）

動画：`episodes/ep25/out/ep25.mp4`

この回は**広告（PR）**です。プロフィールに置くBrainの紹介リンクから買われると、ためひろさんに紹介報酬が入ります。広告だと分かるようにしているのは次の4か所です。
- 画面：0秒目から最後まで、左上に「PR・紹介報酬あり」のラベル（濃紺の「PR」＋白地の「紹介報酬あり」）
- 声：2文目（PRであること）、3文目（紹介の仕組みのたとえ）、16文目（「プロフの紹介リンク」）。4文目は無料部分を見る案内で、「僕に紹介料が入る」とは声では言っていない（ユーザーの希望で差し替え）。紹介報酬があることは、ずっと出るラベルと各キャプションの1行目・紹介の段落で示す
- 見出し：2文目に「これはPRやで」、3文目に「紹介の仕組み」
- キャプション：1行目

## 投稿前のチェック

  - 5文目は「ほかにも」で、明鏡とは別の話だと示している（ユーザーの希望で「ほかの店にも」から変更）。「有益な情報」が明鏡の中身のことに聞こえると、明鏡を試して（買って）紹介してみて、と取られるので、6文目は削らない。コメントで「明鏡を買って紹介したらええの？」と聞かれたら、下の「買ったら僕も紹介で稼げる？」と同じ返しをする
  - 明鏡の公式FAQでは、明鏡を紹介できるのは**買った後**（紹介報酬は当面50%）とされている。なので「明鏡を買って、あなたも紹介して紹介料を」とつなげると、「買う→人に紹介すると報酬」という連鎖販売取引（いわゆるモノなしマルチ）と同じ形になる。動画でもキャプションでもコメントでも、この2つを結び付けない。6文目はそのための1文なので、尺が足りなくても削らない
  - 「1件売れたら1万4,900円」「2件で元が取れる」「半額返ってくる」「紹介料50%」は言わない・書かない

### 言わない・書かないこと（コメント欄も同じ）
- 「稼げる」「月○万」「誰でも」「すぐ」「最強」「No.1」「人生変わる」
- 「クーポン」「お得に買える」「僕のリンクから買うと安い」：割引はない
- 「明鏡を買えば紹介で元が取れる」「あなたも明鏡を紹介して稼げる」「紹介料50%」「1件で1万4,900円」：買うことと紹介料を結び付けない（連鎖販売取引の形になる）
- 「今だけ」「もうすぐ締め切り」「今月中に」「次の受付は○日から」「値上げ前に急いで」
- 値上げ予定（49,800円）：急がせる言い方になり、二重価格にも見えるため書かない
- 「案件ちゃうで」「第三者の正直な感想」「ステマちゃう」：紹介報酬がある以上、広告として扱う
- 「イケハヤさん公認」「コラボ」「イケハヤさんが教えてくれる」：提携や直接の指導があるように見せない。イケハヤさんの写真・ロゴ・販売ページの画像も使わない
- 「失敗例が全部載ってる」「どんな商売でも成功する」：ためひろさんの感想として言う。教材の中身を言い切らない
- イケハヤさんの売上の数字（「数億円」「約5億円」など）：今回は動画からもキャプションからも外した。権威づけになり、出どころでも数字が違う
- 「専門教材」：本人は「初学者向け」と書いている。「マーケティングの教材」と言う
- 「25万字」「講義動画1,200本」「2600部突破」：確かめられていない、または、みんな買っていると思わせる数字
- 「教材に台本のテンプレが入ってる」「AIに読み込ませてOK」：確認できていない
