# 設計図：YouTube チャンネル（しのびのゲーム工房）

- 版: 2026-10-06（初版）
- 状態: **設計のみ・未開設**（チャンネルの開設、投稿、数字の記録はまだしていません）
- 元にした考え方: おさる「おさるのマーケネタ帳」の5ステップ（チャンネル設計 → 企画 → 台本 → 投稿 → 導線と数字）。本人から依頼文として受け取った要点を、このサイトの事情に合わせて組み直しました
- 関係する書類: [SNS自動投稿の設計図](../BLUEPRINT.md)／[事実台帳](../OFFER_FACTS.md)／[判断ログ](../ledgers/DECISIONS.md)

## 0. ひとことで

**誰の、どの悩みに答えるかを先に決める → 見つけてもらう動画と深く学んでもらう動画を分けて作る → 週1本を当てにいく → 見終わった人が「遊ぶ」「メルマガに登録する」まで動ける道を用意する → 数字で次に直す場所を1つ決める**

登録者が増えてから受け皿を考えるのではなく、**最初から受け皿（週刊メルマガとゲーム）まで一本の道で設計する**のがこの設計図の柱です。AIで動画はそれっぽく作れるようになったので、本数ではなく「誰に・何を・見た後どう動いてもらうか」で差をつけます。

> この設計図に出てくる数字の目安（クリック率5%、平均再生率30%、入口8割:深掘り2割、リサーチ条件など）は、元の話し手が**自分の改善のために挙げた目安**です。YouTube 公式の合格基準ではありません。自分のチャンネルの平均と比べて使います。

## 1. 全体図

```
[STEP1 設計]  誰に／どの悩みを／なぜ自分が  を3行で書く
   │          チャンネル名・アイコン・ヘッダー・説明文をその3行にそろえる
   ▼
[STEP2 企画]  入口の動画（広く見つけてもらう）8 : 深掘りの動画（信頼を育てる）2 で始める
   │          ネタは自分の頭からではなく、伸びている小さなチャンネルの「切り口」から借りる
   │          タイトルとサムネで同じことを言わない（2つで見る理由を作る）
   ▼
[STEP3 台本]  オープニング（1分以内）→ 本編（視聴者の言葉・PREP・3つのポイント）→ CTA → エンディング
   ▼
[STEP4 投稿]  週1本。AIで浮いた時間は本数ではなく1本の質に使う
   │          公開から時間がたっても平均を下回る動画は、サムネ・タイトルから直す
   ▼
[STEP5 導線]  共通の特典 ＋ その回だけの特典 → 週刊メルマガ（Substack）／ゲーム本体
   ▼
[数字]        クリック率 → 企画・サムネ・タイトル ／ 平均再生率 → 台本 ／ 離脱位置 → 直す場所
              その先: メルマガ登録数・ゲームへのリンクのクリック → 判断ログに1行
```

SNS（Threads）と同じく、**フォロワーや登録者は借り物、メルマガの読者は自分の資産**という考え方で、YouTube の出口も Substack の週刊メルマガにそろえます。元の話では出口が LINE 登録ですが、このサイトにはすでに Substack の受け皿があるので、受け皿を増やさずにそちらへつなぎます（受け皿を並べて増やさない）。

|---|---|---|---|---|
| P1 | 誰に届けるか | A 小学生の子をもつ保護者 ／ B 謎ときで頭を使いたい40代以上 ／ C 個人でゲームを作りたい人 | **A を主、B を時々** | 公開中のゲームの中心が「家族で遊べる」なので、見終わった後に遊ぶ・登録する道が一番まっすぐつながる。C は別のチャンネル向きの話題 |
| P2 | 「子ども向け」設定にするか | 子ども向け ／ 子ども向けではない（保護者向け） | **子ども向けではない（話しかける相手は保護者）** | 子ども向けに設定した動画は、コメント・カード・終了画面などが使えなくなる。STEP1 のコメント調査や STEP5 の導線が組めなくなるため。SNS の基本ルール（話しかける相手は保護者と大人）とも合う。開設時に YouTube ヘルプの最新の説明で確認する |

| P5 | AIで作った声・画像を使うか | 使う ／ 使わない ／ 一部 | **台本のたたき台と画像の初案だけ** | 経験と言葉は自分で直す（STEP3）。本物に見える合成映像を使う場合は、YouTube の「改変または合成されたコンテンツ」の開示が必要か投稿時に確認する |

## 3. STEP1：話したいことより、視聴者が困っていることから決める

### 3.1 調べる順番（自分の頭の中だけで決めない）

1. 同じジャンルのチャンネルを **3つ** 選ぶ（候補の探し方は §4.3 の条件を使う）
2. 3つそれぞれについて、下の表を埋める
3. 競合の動画の**コメント欄**と、YouTube 検索の**候補**（検索窓に「なぞなぞ 小学生」「親子 遊び 家で」などを入れたときに出る言葉）から、視聴者がすでに書いている悩みを**そのままの言葉で**拾う
4. 拾った言葉の中から、3つのチャンネルが**十分に応えていない悩み・切り口**を探す

| チャンネル | 誰に向けているか | よく扱うテーマ | コメント欄で目立つ悩み（原文のまま） | 応えきれていないこと |
|---|---|---|---|---|
| （記入） | | | | |
| （記入） | | | | |
| （記入） | | | | |

拾った言葉は `_marketing/youtube/voices.md`（なければ作る）に**原文のまま・出典の動画つき**で貯めます。STEP2 の企画、STEP3 の台本で何度も使います。

> 例（P1=A の場合に拾えそうな言葉の形。実際の言葉はリサーチで拾ったものに置き換える）:
> 「雨の日に家で何をさせればいいか分からない」／「ゲームばかりで頭を使う遊びをしない」／「なぞなぞの本はすぐ飽きる」

### 3.2 AI にコンセプトを丸投げしない

AI に頼むなら、**材料を渡してから**にします。何も調べずに「伸びるコンセプトを作って」と頼むと、一般的な答えしか返ってきません。

AI への頼み方（ひな形）:

```
次の3チャンネルを調べた結果です。
- チャンネル1: 名前／誰に向けているか／よく扱うテーマ／コメント欄の悩み（原文）
- チャンネル2: …
- チャンネル3: …
私の材料: 家族で遊べる無料のなぞときブラウザゲームを4本、個人で作って公開している。
（使える事実は _marketing/OFFER_FACTS.md の範囲だけ）
この3チャンネルが十分に応えていない悩みと、切り口の候補を5つ出してください。
それぞれ「誰に／どの悩みを／なぜこの作り手が答えられるか」の3行で。
```

### 3.3 最後は自分の言葉で3行にする

| 項目 | 書く内容 | 下書き（P1=A の場合の例。本人が直す） |
|---|---|---|
| 誰に | 届けたい人を1人思い浮かべられる具体さで | 小学生の子と家で過ごす時間に、何をして遊ぶか困っている保護者 |
| どの悩みを | §3.1 で拾った言葉を使う | 「頭を使う遊びをさせたいけど、本やドリルだと続かない」 |
| なぜ自分が | 事実台帳にある事実だけで | 家族で遊べる無料のなぞときゲームを自分で作り、なぞなぞやすいりの問題を作り続けている |

**絞り込みすぎていないかの点検**:

- [ ] 相手に「自分のことだ」と伝わる具体さがある
- [ ] 新しく困る人が毎年・毎月出てくる広さがある（例:「小学1年生の親だけ」より「小学生の親」）
- [ ] この3行で「話すこと」と「話さないこと」が分けられる（例: 中学受験の勉強法は話さない）

### 3.4 チャンネルの見え方を中身とそろえる

動画からチャンネルに来た人が「何を教えてくれる人か」で迷わない状態にします。

| 部品 | そろえ方 |
|---|---|
| チャンネル名 | 3行の「誰に」か「どの悩みを」が伝わる言葉を入れる。サイト名「しのびのゲーム工房」との関係が分かるように |
| アイコン | サイトと同じキャラクター（CC0 の CryptoNinja / CNP）。「公式」と誤解される表現は使わない（事実台帳の「言ってはいけないこと」） |
| ヘッダー | 3行の「誰に・どの悩みを」を1文で。投稿の曜日（例: 毎週○曜） |
| 説明文 | 3行をそのまま。サイト・メルマガのリンク。個人制作であること |
| 再生リスト | 「入口の動画」と「深掘りの動画」をテーマごとにまとめる（§4.1） |

## 4. STEP2：見つけてもらう動画と、深く学んでもらう動画を分ける

### 4.1 2種類の企画

| 種類 | 役割 | 比率（始め方） | 例（P1=A の場合の案） |
|---|---|---|---|
| 入口の動画 | 広い層に見つけてもらう | **8** | 「小学生がつまずくなぞなぞ5選」「親が先に解けないとくやしい謎3問」「雨の日に家でできる、頭を使う遊び5つ」 |
| 深掘りの動画 | この人から学びたいという信頼を育てる | **2** | 「親子でなぞときを毎日5分続ける進め方」「子どもが自分で謎を作れるようになる順番」「暗号の謎を1本で全部わかる」 |

- 入口がなければ深掘りまで来てもらえない。入口だけでは信頼が育たない。**どちらか片方ではなく両方**。
- 比率の変え方: コメントやメルマガ登録などの反応が出てきたら、深掘りの比率を上げる（例: 8:2 → 7:3 → 6:4）。変えたら判断ログに1行。
- 動画で使う謎・問題は、ゲームと同じ種類（なぞなぞ・すいり・めいろ・あんごう など）を新しく作るか、ゲームの問題を紹介する。効果の断言（「頭が良くなる」「成績が上がる」など）はしない。

### 4.2 4週ぶんの企画表（下書き。本人が直す）

| 週 | 種類 | 仮タイトル | サムネで足すこと（タイトルと重ねない） | その回の特典（§7） |
|---|---|---|---|---|
| 1 | 入口 | 小学生がつまずくなぞなぞ5選 | 「大人も3問目で止まる」など意外さ | 5問の印刷用シート |
| 2 | 入口 | 家で5分、親子でできる頭を使う遊び5つ | 遊んでいる手元の絵と「準備0分」 | 遊びのチェックリスト |
| 3 | 入口 | 暗号を解くと、子どもが自分で暗号を作り出す | 暗号の実物（一部だけ見せる） | 暗号の表と練習問題 |
| 4 | 深掘り | 親子でなぞときを毎日5分続ける進め方 | 1週間の流れの図 | 1週間のスケジュール表 |

### 4.3 企画の材料はリサーチから借りる

伸びている動画を探す目安（元の話し手の目安。これで再現性が保証されるわけではなく、比べる候補を絞るための条件）:

- [ ] 投稿から **半年以内**
- [ ] できれば登録者 **1万人以下**
- [ ] 再生数が登録者数の **2倍以上**

大きなチャンネルだから見られた動画ではなく、**切り口が効いていそうな動画**を探すための条件です。まず自分のジャンルで **3本** 見つけ、下の表を埋めます。

| 動画 | なぜ見たくなったか（1文） | 取り出した型 | 自分の相手・経験に置き換えると |
|---|---|---|---|
| （記入） | 例: みんなが正しいと思っているノート勉強を否定していた | 「正しいと思われている行動を見直す」 | 例: 「なぞなぞの本を1冊やらせる」が続かない理由 |
| （記入） | | | |
| （記入） | | | |

**型は借りても、中身まで持ってこない。** 同じ問題・同じ台本・同じサムネは使いません。

### 4.4 タイトルとサムネで同じことを2回書かない

| 悪い例 | 良い例 |
|---|---|
| タイトル「小学生がつまずくなぞなぞ5選」／サムネ「なぞなぞ5選」 | タイトル「小学生がつまずくなぞなぞ5選」／サムネ「大人も3問目で止まる」 |

サムネを作る前に、次の順で決めます（デザインを頑張る前に「何を伝える画像か」）:

1. タイトルが伝えること（内容）
2. サムネが足すこと（その結果どうなるか／何が意外か）
3. §4.3 の3本のサムネを並べて、文字量・色・人（キャラクター）の見せ方の共通点を見る
4. その企画に合う表情・身ぶり・背景のキャラクターを選ぶ（毎回同じ絵を置かない）
5. 文字は詰め込まず、余白を残す。スマホの小さな画面で一目で何の動画か分かるか確かめる

顔出しをしない（P3）ので、表情の代わりにキャラクターの身ぶりと、謎の図そのものを使います。画像は Canva で作れます（SNS の画像と同じ作り方。[README](../README.md#画像を付けるときcanva)）。

## 5. STEP3：台本は、話す内容だけでなく「見る順番」を作る

### 5.1 台本のひな形

```
タイトル（仮）:
種類: 入口 ／ 深掘り
この回で解決する悩み（視聴者の言葉で）:
見終わった人にしてほしいこと: （その回の特典を受け取る ／ ゲームで遊ぶ）

■ オープニング（15分以内の動画なら1分以内）
- この動画で何が分かるか（結論の予告）
- 見る理由（この悩み、ありませんか？ ← 視聴者の言葉）
- 自己紹介は一言だけ（毎回同じ長い自己紹介はしない）

■ 本編（3つのポイント）
今日のポイントは3つ: ①… ②… ③…
ポイント①
  結論:
  理由:
  具体例（自分の経験・ゲームを作っていて気づいたこと）:
  もう一度結論:
ポイント②（同じ形）
ポイント③（同じ形）

■ CTA（中身を届けた後に）
- この回の内容を実際にやるための特典の案内（§7）
- 「いま、ポイント③の話をしました」のように、どこまで来たか分かる一言をつけてから案内する

■ エンディング
- 3つのポイントを一言ずつ
- 次に見てほしい動画（入口 → 深掘りへ）
```

### 5.2 本編で守る3つ

1. **視聴者が実際に使っている言葉を入れる**（§3.1 で拾った言葉。`voices.md` から選ぶ）
2. **伝える順番を整える**: 結論 → 理由 → 具体例 → もう一度結論（PREP）
3. **全体が見える形にする**:「3つのポイント」と最初に言い、今どこの話かを言いながら進める

### 5.3 オープニングの点検

- [ ] 長い挨拶・毎回同じ自己紹介・本題までの前置きで時間を使っていない
- [ ] 15分以内の動画なら1分以内（長い解説や、誰が話すかを伝える必要がある回は別の組み方でよい。時間を機械的にそろえるのではなく「その説明が本題を見る理由になっているか」で判断する）

### 5.4 AI に任せること・任せないこと

| 工程 | AI | 自分 |
|---|---|---|
| 構成のたたき台（3つのポイントの候補、PREP の形） | ○ | 選ぶ・直す |
| 視聴者の言葉の選び方 | 候補出しまで | 決める |
| 経験・具体例 | × | 自分で書く（ゲームを作っていて気づいたこと、遊んだ人の反応など。家族の個人情報は出さない） |
| 言い回しを自分の言葉に直す | × | 自分で直す |
| 事実の確認 | × | 事実台帳と照らす |

AI に頼むなら（ひな形）:

```
次の企画の台本のたたき台を作ってください。
- 誰に: （§3.3 の3行）
- この回で解決する悩み（視聴者の言葉）: 「…」
- 種類: 入口 ／ 深掘り、長さの目安: ○分
- 形: オープニング1分以内 → 本編は3つのポイント、それぞれ結論・理由・具体例・結論 → CTA → エンディング
- 具体例の欄は空けておく（私が自分の経験で書きます）
- 使ってよい事実は次のものだけ: （事実台帳から貼る）
```

## 6. STEP4：毎日出すことより、1本を当てにいく

### 6.1 週1本の作業の流れ（目安）

SNS の日曜の作業（[README](../README.md#毎週やること日曜15分)）と重ならないように置きます。曜日は本人が決めます。

| 日 | やること | 目安 |
|---|---|---|
| 1日目 | 企画を1本決める（§4.2 の表から）。リサーチの表を1行足す | 30分 |
| 2日目 | 台本（AI のたたき台 → 自分の経験と言葉で直す） | 60〜90分 |
| 3日目 | 収録・画面の録画・編集 | 本人の作り方次第 |
| 4日目 | サムネとタイトル（§4.4 の順）。その回の特典（§7）を1枚作る | 60分 |
| 5日目 | 投稿。説明文に特典とメルマガ・サイトのリンク | 15分 |
| 毎週 | 過去の動画の数字を見て、直す場所を1つ決める（§8） | 15分 |

- **本数を約束するために中身を削らない**。AI で短くなった時間は、本数を増やすのではなく1本の質（経験を入れる・伝わりにくい所を直す）に使う。
- 週1本が無理な週は休む。休んだことは判断ログに残さなくてよい（4週続いたら §9 の撤退条件で見直す）。

### 6.2 出した後の動画を見返す

- 公開直後に良し悪しを決めない。**自分のチャンネルの平均と比べ、時間がたっても下回るもの**を見直す（比べる時期は仮に公開から7日後と28日後。4週の振り返りで決める）
- 見直しは、サムネ・タイトル → 説明文・再生リストの順（動画の中身は投稿後に変えにくいので、学びは次の動画の台本へ）
- 初めて来た人にどう見えるかを月1回点検する: チャンネルのトップ、再生リストの並び、説明文が §3.3 の3行とそろっているか

## 7. STEP5：動画で学んだことを、次の行動につなげる

### 7.1 出口は2つ

| 出口 | 何をしてもらうか | どこへ |
|---|---|---|
| メルマガ（主） | 週刊メルマガに登録してもらう（受け皿＝自分の資産） | Substack（`_marketing/sns/config.json` の links「メルマガ」と同じ URL） |
| ゲーム | 動画で出た謎の続きを遊んでもらう | サイトのトップ、または該当するゲーム |

再生数と、見た人が動くことは別です。**見た人が「やってみよう」と思った時にすぐ使えるもの**を渡します。

### 7.2 特典は2種類

| 種類 | 役割 | 案（本人が決める） |
|---|---|---|
| 共通の特典 | どの動画でも案内できる | 「親子で解く謎とき1か月カレンダー」（1日1問の印刷用シート）など、全体を見渡せるもの |
| その回の特典 | その回の内容を実践するため | なぞなぞの回 → 5問の印刷用シート／暗号の回 → 暗号の表と練習問題／続け方の回 → 1週間のスケジュール表 |

- 毎回大きな教材を作らない。**その回で話した内容を PDF 1枚のチェックリストや問題シートにまとめるだけ**でよい。台本があれば AI に整理してもらい、自分で確認して整える。
- 特典の渡し方（メルマガの登録者に送る、メルマガの記事に載せる など）は、Substack の機能で何ができるかを確かめてから決める（本人判断）。
- 特典に書く事実も事実台帳の範囲だけ。「期間限定」「先着」は使わない（無料でいつでも渡せるので希少性の実態がない）。

### 7.3 案内する順番

1. まず中身を届ける（CTA は本編の後）
2. その中身を実践するために必要なもの（その回の特典）を案内する
3. 共通の特典とメルマガは、説明文・固定コメント・エンディングで

してはいけないこと:

- 価値を届ける前に登録を求める
- どの動画でも脈絡なく同じ誘導を入れる
- 子どもに向けて「登録してね」「リンクを押してね」と呼びかける（話しかける相手は保護者）

## 8. 数字は、落ち込むためではなく「次に直す場所」を決めるために見る

### 8.1 最初に見るのは2つだけ

| 数字 | 意味 | 目安（元の話し手の目安。公式基準ではない） | 低いときに直す場所 |
|---|---|---|---|
| クリック率 | サムネ・タイトルを見た人のうち、動画を開いた割合 | 5%以上 | 企画・サムネ・タイトル |
| 平均再生率 | 動画が平均してどこまで見られたか | まず30%を超える | 台本の順番・長すぎる説明 |

動画の長さや届いた相手で数字は変わるので、**自分のチャンネルの中での比較**も必ずします。

### 8.2 離れた場所から直す所を絞る

| 離れた場所 | 疑うこと | 直し方 |
|---|---|---|
| 冒頭 | 本題までが長い | オープニングを削り、結論の予告を先に |
| 中盤 | 同じ話の繰り返し | ポイントを3つに収め、今どこの話か言う |
| 終盤 | まとめや誘導が長い | まとめを一言ずつに、CTA を短く |

**全部を一度に変えない。低い方の数字につながる部分を1つだけ直して、次の動画で試す。**

### 8.3 週の記録（SNS の週次改善 Issue に1ブロック足す想定）

| 動画 | 公開日 | 種類 | クリック率 | 平均再生率 | 離れた場所 | 次に直す1つ | メルマガ新規登録（その週） |
|---|---|---|---|---|---|---|---|
| （記入） | | 入口／深掘り | | | 冒頭／中盤／終盤 | | |

- 事業として見るのは再生数の先: **メルマガに何人登録したか、そこから返信・相談・ゲームで遊んだという声があったか**。
- 動画からメルマガに来たかを分けて数える方法（Substack 側で登録元が見られるか、動画専用のリンクを使うか）は、開設時に確かめて決める。このサイトにはアクセス解析を入れていないので（事実台帳）、サイト側では数えられない。
- 週次の自動集計に YouTube の欄を足すかは、4週続けて手で写せた後に検討する（計測装置を先に作り込まない。SNS の点検 F4 と同じ方針）。
